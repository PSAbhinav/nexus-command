# NexusCommand 🌌

![NexusCommand Banner](https://images.unsplash.com/photo-1614064641938-3bbee52942c7?q=80&w=2070&auto=format&fit=crop)

> **A futuristic, cyberpunk-inspired personal command center for productivity, finance, and habit tracking.**

NexusCommand is a premium React application designed to organize your digital life with style. Featuring a deep "Midnight Aurora" aesthetic, glassmorphism UI, and fluid animations, it turns mundane tasks into a high-tech experience.

---

## ✨ Features

### 🎨 Premium UX/UI
- **Midnight Aurora Theme**: Deep navy backgrounds with electric teal/cyan accents and drifting aurora mesh animations.
- **Glassmorphism**: Frosted glass cards and sidebars for depth and hierarchy.
- **Micro-Interactions**: 3D tilt effects, magnetic buttons, and satisfying ripple clicks.
- **Fluid Transitions**: Cinematic scale-up page reveals and animated number counters.

### 🚀 Core Modules
- **📊 Dashboard**: At-a-glance overview of your day, finances, and health metrics.
- **💰 Finances**: Track income, expenses, and savings with interactive charts.
- **✅ Tasks**: Kanban-style task management with focus timers and priority sorting.
- **🎯 Goals & Habits**: Build consistency with habit streaks and goal progress tracking.
- **❤️ Health**: Monitor mood, sleep, and hydration trends.
- **⚙️ Settings**: Customizable accents, font sizes, and privacy controls (auto-lock).

### 🔒 Security & Privacy
- **Local-First**: All data is stored locally in your browser using AES-256 encryption.
- **Privacy Mode**: Auto-lock functionality after customizable inactivity periods.
- **Data Export**: Full control to export/import your encrypted data anytime.

---

## 🛠️ Tech Stack

- **Framework**: React 18 (Vite)
- **Styling**: Pure CSS Variables, CSS Modules, Advanced Keyframe Animations
- **Icons**: Lucide React
- **Charts**: Chart.js / React-Chartjs-2
- **State Management**: React Hooks (Context-free for performance)
- **Encryption**: AES-GCM (Web Crypto API)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/yourusername/nexus-command.git
    cd nexus-command
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

4.  **Build for production**
    ```bash
    npm run build
    ```

---

## ☁️ Deployment

### Vercel (Recommended)

NexusCommand is optimized for Vercel.

1.  **Install Vercel CLI** (optional, or use the web dashboard)
    ```bash
    npm i -g vercel
    ```

2.  **Deploy**
    Run the following command in the project root:
    ```bash
    vercel
    ```
    Follow the prompts. Vercel will automatically detect the Vite settings.

3.  **Production Deployment**
    ```bash
    vercel --prod
    ```

### Manual Deployment
The `dist` folder generated by `npm run build` can be hosted on any static site provider (Netlify, GitHub Pages, Surge, etc.).
